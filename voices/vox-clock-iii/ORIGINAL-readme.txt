Radio Shack VoxClock III (AKA Spartus Talking Clock)
by MaryAnn Topolewski and Patrick Perdue
May 29, 2005

This archive contains two clocks: VoxClockIII and VoxClockIII chimes.
Since this clock bongs the hour in a highly annoying way rather than speaking it, both the talking and chiming bits are included separately.
This clock was not able to be recorded with an EM pick-up coil due to it's built-in transformer, so this is an indirect mic pickup using a Cad Equitek E300 studio condenser. Overkill to the max!
