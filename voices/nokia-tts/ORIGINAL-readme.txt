NokiaTTS (Low Quality)
by Patrick Perdue
June 03, 2007

This clock was made using the Nokia TTS engine, which ships with all Nokia s60v3 phones, and some newer s60v2 phones, such as the Nokia N70.
This was recorded using a Nokia E61, which does not have a flat frequency response, and lacks some natural low-end. This was compensated for, using a parametric EQ.
The synthesizer has a horrible lexicon, so some things were deliberately misspelled to obtain the proper pronunciation.
